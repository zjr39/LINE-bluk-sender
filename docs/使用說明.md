# LINE 聯絡人批量助手 — 使用說明

批次發送訊息、批次貼標籤、匯出聯絡人清單。設定一次、重複使用。

---

## ⚠️ 先讀這段

- 這個工具會**真的把訊息送給客戶**，送出後無法收回。
- 第一次使用，**一定要先小範圍測試**（發文字用「從/到」只跑 1 位；發圖用「試送一張」），確認正確再跑全部。
- 發送前請確認你有權限對這些聯絡人發送訊息。

---

## 📦 你會拿到的資料夾

```
LINE-bluk-sender\
├── 安裝說明.html          ← 安裝步驟（雙擊用 Edge 開啟）
├── 使用說明.md            ← 本文件
├── start-server.cmd       ← 每次要用之前，雙擊這個
├── server\server.js       ← 服務程式（不用手動開）
└── snippet\line-bulk-paste.js  ← 面板本體（不用手動開）
```

整個資料夾約 **90 KB**，用 LINE 或 Email 傳都可以。
**不用安裝任何擴充功能**，只需要一個書籤加一個執行中的小服務。

## 🖥️ 安裝（三步，約 1 分鐘）

### 第一步：啟動本機服務（每次要用都要開）

1. 進入 `portable` 資料夾。
2. **雙擊 `start-server.cmd`**。
3. 看到這段就成功了：

```
  ✅ 服務已啟動
     面板腳本： http://127.0.0.1:8765/snippet.js
  （保持這個視窗開著，不要關閉）
```

> **沒裝 Node.js**：這個檔案會自動用 winget 幫你裝（需要網路，約 1 分鐘）。
> 裝完請**關掉視窗，再雙擊一次** `start-server.cmd`。
> 若連 winget 都沒有，到 <https://nodejs.org/> 下載 LTS 版，安裝時一路按 Next。

⚠️ **黑色視窗要一直開著**。關掉它，書籤就會失效。

### 第二步：裝書籤小工具（只需一次）

1. 雙擊 `安裝說明.html`（用 Edge 開啟）。
2. 頁面上會顯示服務狀態：綠色可繼續、紅色請回第一步。
3. 按 `Ctrl+Shift+B` 讓 Edge 書籤列出現。
4. 把頁面上那顆**綠色按鈕拖到書籤列**上放開。

> 拖曳沒反應？`Ctrl+Shift+O` 開書籤管理員 →「⋯」→「新增書籤」→
> 名稱填 `LINE 批量助手` → 網址貼上安裝頁最下方那串 → 儲存。

### 第三步：開始使用

1. 登入 LINE 官方帳號管理後台，打開「**聯絡人**」頁面。
2. 點一下書籤列上的「**LINE 批量助手**」→ 畫面**右上角**出現綠色面板。

---

## ✉️ 功能一：批次發送訊息

1. 在面板最上方文字框**貼上要發送的內容**（會自動記住，下次開啟還在）。
2. 按「**掃描全部（反覆載入）**」，等它跑完。
3. 按「**預覽名單**」確認要發給幾位。
4. 把範圍限成 1 位做測試（「從」填 1、「到」填 1），確認訊息正確送出。
5. 確認無誤後按「**開始全部**」。

- 「**粘貼後自動傳送**」預設**開啟**；取消勾選就只貼上、不送出。
- 想中途停：按「停止」（正在處理的那位會完成，其餘不再跑）；按「暫停」可再繼續。

---

## 🏷️ 功能二：篩選要發給誰

面板上黃色「篩選」區：

| 欄位 | 用法 |
|---|---|
| **只發給** | 填標籤或名稱關鍵字。多個用 `,` 分隔，**滿足任一個就發**。例：`VIP,繁體` |
| **排除** | 填不要的關鍵字（優先於「只發給」）。例：`測試,黑名單` |
| **只發好友＋有標籤** | 預設開啟。只發給「類型＝好友」且「有標籤」的對象 |

> **固定規則：類型為「只傳訊的用戶」一律不發**，即使他有 VIP 標籤。
> 這是 LINE 的限制——官方帳號無法對這類用戶發起聊天。

按「**預覽名單**」可在發送前看到會發給誰、排除了幾位。

---

## 📄 功能三：匯出聯絡人 CSV

按「**匯出聯絡人 CSV**」，會下載 Excel 可直接開啟的檔案，欄位為：

```
# | 聯絡人姓名 | 標籤 | 類型 | 狀態 | 最近聊天日期 | 依目前篩選
```

「**匯出結果 CSV**」則是匯出批次執行的成功／失敗明細。

---

## 🏷️ 功能四：批次加標籤

面板上綠色「批次加標籤」區：

1. 在文字框貼上**要加標籤的聯絡人名單**（一行一個名稱）。
2. 「標籤名稱」填要加的標籤，可用 `,` 一次加多個（例：`繁體,英語`）。
3. 按「**預覽符合**」，確認找得到幾位、已有標籤幾位。
4. 按「**開始加標籤**」。已有該標籤的會自動跳過。

流程與手動操作相同：點「新增標籤」→ 輸入 → 按 Enter → 點「儲存」，逐位處理。

---

## 🖼️ 功能五：批次發圖

> **重要：LINE 不允許「只附加圖片、不送出」。**
> 選圖後 LINE 一定會跳「確定要傳送檔案至此聊天室嗎」，按「傳送」就立即發給客戶。
> 本工具會**自動處理這個彈窗並送出**，所以批次發圖是**真的發送**，無法先預覽再決定。

面板上藍色「批次發圖」區：

1. 按「**選擇圖片**」選一張本地圖片（會顯示縮圖，並**記住**，重新整理後自動帶回）。
2. 先按「**試送一張**」——只對**目前開啟的那個聊天室**發送，確認圖片正確。
3. 確認無誤後按「**批次發圖**」→ 對名單（依篩選規則）逐位發送。
4. 「**清除**」可移除已選圖片。

**建議流程**：先「掃描全部」→「預覽名單」確認對象 →「試送一張」→「批次發圖」。

## 🔘 面板按鈕一覽

| 按鈕 | 作用 |
|---|---|
| 掃描聯絡人 | 只抓目前畫面上已載入的列（快速但不完整） |
| **掃描全部（反覆載入）** | **每次開跑前都要按**。清單分批載入，這樣才拿得到完整名單 |
| （測試方式） | 把「從」「到」都設成 1，只跑第一位驗證文案 |
| 開始全部 | 處理「從」到「到」範圍內的對象 |
| 暫停 / 停止 | 暫停可繼續；停止則結束本輪 |
| 檢查輸入框 | 找不到輸入框或送不出去時排錯用 |
| 預覽名單 / 匯出聯絡人 CSV | 見功能二、三 |
| 預覽符合 / 開始加標籤 | 見功能四 |
| 匯出結果 CSV | 匯出批次執行結果 |
| 選擇圖片 / 清除 | 選一張要發送的圖片（會記住） |
| 試送一張 | 只對目前開啟的聊天室發送圖片，驗證用 |
| 批次發圖 | 對名單逐位發送該圖片 |

**面板操作**：右上角 `◢` 拖曳可調整面板大小、`—` 收合、`✕` 關閉。
三個文字框下方各有一條**灰色拖曳條**，可調整該框高度。

## ❓ 常見問題

**Q：點書籤沒反應，或跳出「本機服務沒有啟動」**
A：服務視窗被關掉了。雙擊 `start-server.cmd` 重新啟動，然後在 LINE 分頁按 `F5`，再點一次書籤。

**Q：服務視窗顯示「連接埠 8765 已被占用」**
A：服務已經在執行了（可能你開了兩個）。那個新視窗直接關掉即可。

**Q：面板一直顯示「找不到輸入框」**
A：右側聊天室還沒打開。先點一位聯絡人的「聊天」按鈕讓輸入框出現，再按「檢查輸入框」。

**Q：掃描到的人數比實際少**
A：清單是分批載入的。把面板的「**掃描輪數**」調大（例如 5 或 10），再按一次「掃描全部」。
判斷方法：看面板顯示的「**後 3 位**」是否等於清單真正的最後一位。

**Q：訊息有貼上但沒送出**
A：該筆會記為失敗。請手動送出，並把「間隔(ms)」調大後再試。

**Q：可以只貼上不送出嗎？**
A：可以。取消勾選「**粘貼後自動傳送**」。

**Q：會貼錯人嗎？**
A：每位粘貼前都會**確認目前開啟的聊天室就是目標聯絡人**，不符就跳過並記為失敗。
但**同名聯絡人**無法自動區分（面板會警告）。

**Q：跑的時候我可以做別的事嗎？**
A：**不行**。不要動滑鼠鍵盤、不要切換分頁，否則可能貼錯或中斷。

## 🧰 給要改程式的人

| 檔案 | 說明 |
|---|---|
| `snippet\line-bulk-paste.js` | 面板本體，所有邏輯都在這裡。改完存檔、重新整理 LINE 分頁、再點一次書籤即可生效 |
| `server\server.js` | 只負責把上面的檔案提供給書籤（`http://127.0.0.1:8765/snippet.js`） |

**重新產生這個 portable 資料夾**（在主要開發資料夾執行）：

```
node build\build-portable.js
```

它會複製最新的面板腳本進來，並重新產生 `安裝說明.html`。
