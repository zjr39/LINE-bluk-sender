LINE 聯絡人批量助手

批次發送訊息、批次貼標籤、匯出聯絡人清單。設定一次、重複使用。
⚠ 這個工具會真的把訊息送給客戶
送出後無法收回。第一次使用請務必先小範圍測試（發文字：把「從」「到」都設成 1；發圖：「試送一張」），確認正確再跑全部。

安裝（三步，約 1 分鐘）

第一步：啟動本機服務（每次要用之前都要開）
  1. 在這個資料夾裡雙擊 start-server.cmd。
  2. 會跳出黑色視窗，看到「✅ 服務已啟動」就對了。
  3. 這個視窗要一直開著，用完再關。關掉它，書籤就會失效。

沒裝 Node.js 的話，這個檔案會自動幫你裝（需要網路，約 1 分鐘）；裝完請關掉視窗再雙擊一次。

正在檢查服務狀態…

第二步：安裝書籤小工具（只需一次）
  1. 按 Ctrl+Shift+B，讓 Edge 的書籤列出現。
  2. 把下面這顆綠色按鈕 拖到書籤列上放開。

LINE 批量助手

拖曳沒反應？改用 Ctrl+Shift+O 開書籤管理員 →「⋯」→「新增書籤」， 名稱填 LINE 批量助手，網址貼上本頁最下方那串。

第三步：開始使用
  1. 登入 LINE 官方帳號管理後台，打開「聯絡人」頁面。
  2. 點一下書籤列上的「LINE 批量助手」→ 畫面右上角出現綠色面板。

功能一：批次發送訊息

  1. 在面板最上方的文字框貼上要發送的內容（會自動記住，下次開啟還在）。
  2. 按「掃描全部（反覆載入）」→ 等它跑完。
  3. 按「預覽名單」→ 確認「會發送 N 位」符合預期。
  4. 把範圍限成 1 位做測試（「從」填 1、「到」填 1）→ 去聊天室確認訊息正確送出。
  5. 確認無誤後按「開始全部」。要中途停就按「停止」。

「粘貼後自動傳送」預設開啟；取消勾選就只貼上、不送出。

功能二：篩選要發給誰

面板上的黃色「篩選」區：

欄位用法
只發給填標籤或名稱關鍵字。多個用 , 分隔，滿足任一個就發。例：VIP,繁體
排除填不要的關鍵字（優先於「只發給」）。例：測試,黑名單
只發好友＋有標籤預設開啟。只發給「類型＝好友」且「有標籤」的對象
固定規則：類型為「只傳訊的用戶」一律不發，即使他有 VIP 標籤。
（LINE 官方帳號本來就無法對這類用戶發起聊天，硬發也不會成功。）

按「預覽名單」可在發送前看到會發給誰、排除了幾位。

功能三：匯出聯絡人 CSV

按「匯出聯絡人 CSV」會下載一份 Excel 可直接開的檔案，欄位：

#、聯絡人姓名、標籤、類型、狀態、最近聊天日期、依目前篩選

（「匯出結果 CSV」則是匯出批次執行的成功／失敗明細。）

功能四：批次加標籤

面板上綠色「批次加標籤」區：

  1. 在文字框貼上要加標籤的聯絡人名單（一行一個名稱）。
  2. 「標籤名稱」填要加的標籤，可用 , 一次加多個（例：繁體,英語）。
  3. 按「預覽符合」→ 確認找得到幾位、已有標籤幾位。
  4. 按「開始加標籤」。已有該標籤的會自動跳過。

流程與手動操作相同：點「新增標籤」→ 輸入 → Enter → 點「儲存」，逐位處理。

功能五：批次發圖

重要：LINE 不允許「只附加圖片、不送出」。
選圖後 LINE 一定會跳「確定要傳送檔案至此聊天室嗎」的確認彈窗，按「傳送」就立即發給客戶。 本工具會自動處理這個彈窗並送出——所以批次發圖是真的發送，無法先預覽再決定。

面板上藍色「批次發圖」區：

  1. 按「選擇圖片」選一張本地圖片（會顯示縮圖，並記住，重新整理後自動帶回）。
  2. 先按「試送一張」——只對目前開啟的那個聊天室發送，用來確認圖片正確。
  3. 確認無誤後按「批次發圖」→ 對名單（依篩選規則）逐位發送。

「清除」可移除已選的圖片。

建議：發圖前先用「報告名單」確認對象正確；正式跑之前務必先「試送一張」。

重要提醒

  • 執行時不要動滑鼠鍵盤、不要切換分頁，否則可能貼錯或中斷。
  • 請先確認清單已依「姓名」排序，面板會依目前順序由上往下跑。
  • 清單是分批載入的，一定要先按「掃描全部」，否則會漏掉後面的聯絡人。
  • 同名聯絡人無法自動區分，面板會提出警告。
  • 每位粘貼前都會確認目前開啟的聊天室就是目標對象，不符就跳過，不會貼錯人。

常見問題

  • 點書籤沒反應 / 跳出「本機服務沒有啟動」 → 雙擊 start-server.cmd，然後在 LINE 分頁按 F5 再點一次書籤。
  • 服務視窗說連接埠被占用 → 服務已經在跑了，那個視窗直接關掉即可。
  • 面板顯示找不到輸入框 → 先點一位聯絡人的「聊天」讓右側輸入框出現，再按「檢查輸入框」。
  • 掃描到的人數比實際少 → 把面板的「掃描輪數」調大（例如 5 或 10），再按一次「掃描全部」。判斷方法：看面板顯示的「後 3 位」是否等於清單真正的最後一位。
  • 訊息有貼上但沒送出 → 該筆會記為失敗，請手動送出，並把「間隔(ms)」調大後再試。
  • 想中途停止 → 按「停止」。正在處理的那一位會完成，其餘不會再跑。
